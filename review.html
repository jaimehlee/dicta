How this works

  1. Open each release below and find the line worth quoting.
  2. Click Fill the form, type the quote exactly as written (14 words or fewer), tick the checklist, and click Add quote.
  3. Tick Done on each release you've finished, even if you didn't quote it.
  4. Copy the two outputs at the bottom into data/quotes.json and data/pending.json on GitHub (open the file, click the pencil, select all, paste, commit).
  5. The site checks the files and updates in a few minutes. If something's wrong, the old version stays up and GitHub emails you what to fix.
